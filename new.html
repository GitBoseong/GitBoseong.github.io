How publishing works

  1. Complete the form and choose a photo if needed.
  2. Select Save to website folder, then choose the local folder containing this website.
  3. Commit and push the changed files to GitHub. The new post will then appear on the News page.

The browser never receives your GitHub password. Folder access is requested only when you press the save button.
