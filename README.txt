Setup
1. Copy index.html, styles.css, theme.js, and the assets directory to the root of your GitHub Pages repository.
2. Keep your existing profile and metadata images in the images directory.
3. The website opens in dark mode by default.
4. The upper-right theme button switches between dark and light modes.
5. The selected theme is remembered in the browser using localStorage.
6. Printing automatically uses a white, paper-friendly layout.
